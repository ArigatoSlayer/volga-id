# volga-it

# Основное задание

1. http://localhost:8081/api/authentication/swagger-ui.html - сервис регистрации, авторизации и аутентификации.

2. http://localhost:8082/api/hospital/swagger-ui.html - сервис регистрации больниц.

3. http://localhost:8083/api/timetable/swagger-ui.html - сервис регистрации расписания по больнице и бронирования талонов.

4. http://localhost:8084/api/history/swagger-ui.html - сервис сохранения истории посещений.

# Не входило в задание, но я добавил

http://localhost:8080/ - gateway для проверки авторизации. Просьба проводить через него все запросы.

http://localhost:8761/ - Eureka сервер для регистрации серверов в одном месте.

# Брокер сообщений

Для данного задания я выбрал RabbitMQ, так как его настройка была проще, а текущие задачи, как мне показалось, больше подходили для решения через данный брокер сообщений. С помощью брокера сообщений проводится проверка на валидность введённых данных, а также создание документов при бронировании абонентов.

# Развертывание

Приложение запускается после выполнения команды `docker-compose up -d`

# Примечание

В Swagger иногда не проходит заголовок `Authorization`, и если вас не затруднит, то дергать ручки желательно через Postman или его аналоги.
