# volga-it

## Основное задание
1. http://localhost:8081/api/authentication/swagger-ui.html - сервервис регистрации, аторизации, аутентификации
2. http://localhost:8082/api/hospital/swagger-ui.html - сервис регистрации больниц
3. http://localhost:8083/api/timetable/swagger-ui.html - сервис регистрации расписания по больнице, и брониированию талонов
4. http://localhost:8084/api/history/swagger-ui.html - сервис сохранения истории посещений

### Не входило в задание, но я добавил
http://localhost:8080/ - gateway для проврки авторизации. Просьба проводить через него все запросы

http://localhost:8761/ - eureka сервер, для регистрации серверов в одном месте

### Брокер сообщений
Для данного задания я выбрал RabbitMQ, так как его настройка, была проще, а текущие задачи, как мне показалось больше подходили для решения через данный брокер сообщений.
С помощью брокера сообщений проводится проверка, на валидность введыных данных, а так же создание документов, при юронировании абонентов.

## Развертывание
Приложение завпускается после выполнения команды `docker-compose up -d`

### Примичание
в swagger иногда не проходит заголовок `Authorization`, и если вас не затруднит то дергать ручки желательно через Postman или его аналоги
